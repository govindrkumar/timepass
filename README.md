# GFM CLI TOOL
It is my first tool created while learning C++. I am creating a simple CLI tool to replicate what I usually use in linux already through C++.

## Tech Stack Used:
- C++
- Human Intelligence (Govind)

## Tools
1. **Number Guessing game**
- can be played by typing `numgame` or `ng` in terminal. 

2. **Calculator**
- can be turned on by typing `calc`. I am still figuring out compiler in this. 

3. **Todo**
- It lives inside your terminal. No memory for now....
- Type `task add <your task name>` to add task
- Type `task rm <your task number>` to remove task
- Type `task` to assess the list of your task. 

4. **whoami**
- Classic tool written in linux distros to know the username. But, here I am gonna ask your username beforehand. (no peeking in your personal stuff!)

5. **cat**
- Command used to `read` the file inside your command prompt/terminal.
